# 俯视 3D 动作 RPG 面试 Demo

这是一个用于 Unity 客户端岗位面试展示的小型游戏 Demo。项目目标不是做“大而全”的游戏，而是在 3-5 分钟体验内展示工程完整度、代码组织、数据驱动、UI 流程、测试意识和可扩展设计。

## 当前版本

- 版本号：`v0.1.2`
- 阶段：第一阶段，Unity 打开项目后的可见体验修复
- Unity 目标版本：`6000.4.10f1`
- 目标平台：Windows x64

## 当前状态

本阶段已创建项目基础目录、版本文件、Unity 包配置、主菜单/战斗场景和基础 C# 脚本。当前使用的 Unity 编辑器路径为 `E:\Unity\Hub\Editor\6000.4.10f1\Editor\Unity.exe`。Unity 批处理已成功生成基础场景和原型材质，并新增编辑器启动引导，避免打开项目后停留在 Unity 默认空场景。

## 规划体验

- 主菜单进入战斗关卡
- 玩家完成移动、鼠标朝向、攻击、闪避和生命值流程
- 关卡包含 2-3 波敌人和一个精英敌
- 完成胜利/失败结算并返回主菜单
- 最终展示文字全部使用中文

## 工程重点

- 使用清晰模块边界：流程、玩家、战斗、敌人、波次、UI 分离
- 使用 `ScriptableObject` 承载玩家、敌人、技能和波次数值
- 让核心规则尽量独立于 Unity 场景，方便写 EditMode 测试
- 用薄 `MonoBehaviour` 连接 Unity 组件、场景对象和表现层
- 每个阶段更新版本号、中文变更说明，并提交 Git

## 操作说明

第一阶段还没有完整战斗玩法。Unity 编辑器打开项目后，如果当前是默认空场景，项目会自动切到主菜单场景：
