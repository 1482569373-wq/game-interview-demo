# 俯视 3D 动作 RPG 面试 Demo

这是一个用于 Unity 客户端岗位面试展示的小型游戏 Demo。项目目标不是做“大而全”的游戏，而是在 3-5 分钟体验内展示工程完整度、代码组织、数据驱动、UI 流程、测试意识和可扩展设计。

## 当前版本

- 版本号：`v0.2.0`
- 阶段：第二阶段，玩家基础操作和战斗 HUD
- Unity 目标版本：`6000.4.10f1`
- 目标平台：Windows x64

## 当前状态

本阶段已创建项目基础目录、版本文件、Unity 包配置、主菜单/战斗场景和基础 C# 脚本。当前使用的 Unity 编辑器路径为 `E:\Unity\Hub\Editor\6000.4.10f1\Editor\Unity.exe`。第二阶段已接入玩家移动、鼠标朝向、普通攻击、闪避、生命值、训练靶受击反馈和基础 HUD。

## 规划体验

- 主菜单进入战斗关卡
- 玩家完成移动、鼠标朝向、攻击、闪避和生命值流程
- 关卡包含 2-3 波敌人和一个精英敌
- 完成胜利/失败结算并返回主菜单
- 最终展示文字全部使用中文

## 工程重点

- 使用清晰模块边界：流程、玩家、战斗、敌人、波次、UI 分离
- 使用 `ScriptableObject` 承载玩家、敌人、技能和波次数值
- 让核心规则尽量独立于 Unity 场景，方便写 EditMode 测试
- 用薄 `MonoBehaviour` 连接 Unity 组件、场景对象和表现层
- 每个阶段更新版本号、中文变更说明，并提交 Git

## 操作说明

Unity 编辑器打开项目后，如果当前是默认空场景，项目会自动切到主菜单场景：

- `Assets/_InterviewDemo/Scenes/MainMenu.unity`
- `Assets/_InterviewDemo/Scenes/CombatDemo.unity`

按下 Unity 顶部播放按钮后，可以在主菜单点击“开始游戏”进入战斗 Demo 场景。

第二阶段操作方式：

- `WASD` 或方向键：移动玩家。
- 鼠标移动：控制玩家朝向。
- 鼠标左键或 `J`：普通攻击。
- 空格或鼠标右键：闪避。
- HUD 会显示玩家生命、训练靶生命、攻击冷却、闪避冷却和当前战斗反馈。
